# AI Content Intelligence Engine

AI Content Intelligence Engine is an AI-powered content intelligence automation system that will ingest external content signals, normalize and store data, detect valuable content opportunities, use Groq-hosted LLMs for analysis and content generation, and include human approval through Telegram.

## Planned architecture

RSS + Apify

n8n

Normalization

Supabase

Semantic Similarity Layer

Opportunity Scoring

Groq LLM Generation

Telegram Approval

## Planned tech stack

- n8n
- Supabase
- PostgreSQL
- pgvector
- Groq API
- Apify
- RSS
- Telegram API
- GitHub
